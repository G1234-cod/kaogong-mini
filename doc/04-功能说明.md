# 04 · 功能说明

> 逐页行为细节，以 kaogong-mini 当前实现为准。旧版 PWA 的完整交互细节见旧项目 `doc/04-功能说明.md`，功能语义一致处本文只记要点与 Taro 迁移差异。

## 今日页 `pages/today`（791 行，最大页面）

- `useNow()` 每 30s 心跳刷新，全部"到点"判断基于 `nowMin()`
- **倒计时卡**常驻置顶：取未过期最早考试，天数大字 + 考试名 + 日期含周几；下方一行小字列其余考试；无考试引导去课程页
- **闪卡复习区**（紧跟倒计时）：`notes` 中 `nextReviewDate` 到期的时政卡翻面复习（认识推进艾宾浩斯 1/2/4/7/15 天，忘记归零；5 档毕业）——"打开即见"是唯一提醒方式（原则底线：页面内呈现）
- **天气卡**：进入自动定位（`getFuzzyLocation` → 后端反查代理，成功才覆盖手动城市；设置 → 天气城市提供「恢复自动定位」）；手动城市来自内置点选或搜索（搜索候选**必须用户点选**——旧版"洛阳→福建洛阳镇"事故教训）；10 分钟缓存
- **每日一句**：本地库日更（刷新不变）；点 🔄 先给一言（后端代理），**不自动替换本地句**（旧版自动替换出怪句被否决）
- **今日事项**：手写项不限量 + **到期待办（todos.dueDate）自动滚入**；默认展示 4 行、超出内部滑动，完成可勾选（手写项可删）
- **三餐卡**：餐时 ±120 分钟窗口内显示互动卡（吃过了/跳外卖/帮我选）；窗口外常驻"下一餐"预告
- **喝水**：间隔判定 + 50 道常识判断题（25 判断+15 选择+10 旧题，答对/答错/看答案三路径都计入；localStorage 防连续重复）；**答错自动入错题本**（`quizBook` 域，今日再答优先抽未掌握题；错题本入口在时政收集页）
- **睡眠督促**：仅 19:30 后显示（≥sleep-30 或 <wake 判定 due）
- **今日打卡**快捷入口

## 课程页 `pages/courses`

- 考试 CRUD：按名称关键词自动识别模板（国考/省考→civil、四六级→cet、考研→kaoyan、教资→teacher、期末→final、识别不出 generic）；`MilestonePickerModal` 弹窗勾选候选节点（相对考试日自动算日期，已过日期自动 done）后生成；已过日期节点自动标 done
- 录播课进度：expectedPct 按时间轴推算，落后>4% 标红；倒排"每天需看节数"；+1 快捷记录

## 打卡页 `pages/checkin`（968 行）

- 打卡列表：卡片固定高度内 ScrollView 滑动 + 底部渐隐；已勾沉底（数组顺序=勾选先后）；支持**父子项**（父一行全勾；记子项 id；父项当天勾任一子项即算打卡）
- 连续天数/全勤连击/最佳连击：父子项感知版实现（`streakForItem` 等页内函数）；**今天没打不清零**
- **热力图三档**（周/月/年可翻历史、不能翻未来）：周=7 天条形；月=整月日历格（7 列，二元色）；年=12 个月聚合色块。⚠️ CSS 特异性历史教训：覆盖样式必须确认特异性 ≥ 原规则且定义顺序靠后
- **奖励任务卡**：任务进度条（限高 4 条滑动）+ 隐藏任务提示条「🎁 悄悄说：还有 N 个隐藏任务」；机制详见 [05](./05-任务与奖励体系.md)
- **奖券袋**：`coupon-card` 展示（可用/待兑换 code/已使用三态，点击核销）
- **盲盒庆祝弹窗**：新达成任务进 `boxQueue` 队列逐个弹（`.box-overlay` 礼盒开盖 + ✨ + 券面 + 兑换码）
- **心情记录**：5 档 emoji 带文字标签（糟糕/低落/一般/还行/开心），一句话需显式「记下」；mood≤2 当日首触发情绪安慰彩蛋（后端 GLM 生成，研友口吻，失败回落本地语录；同日一次）

## 生活页 `pages/life`

7 宫格入口（吃什么/记账本/待办清单/周期提醒/重要日期/时政收集/番茄钟），带待办未完成数 + 周期任务到期角标。

## 二级工具页

- **吃什么** `pages/food`（617 行）：餐次按时段自动选；双排筛选「想吃（多选交集）+ 不吃（负向剔除）」实时显示"剩 N 个候选"；老虎机抽签（收藏 3 倍权重，18 次递减动画）；就吃它（记 foodLog，当天自动避开）/换一个/复制菜名；候选池按餐次增删收藏；**「问问小助手」按钮跳 AI 对话页**（带吃什么场景上下文）；**唤起美团外卖 `navigateToMiniProgram`**（appId 常量查证填入，失败 toast）
- **AI 对话** `pages/ai-chat`：通用对话（后端 GLM 代理，Markdown 纯文字渲染，不再吐 JSON）；从「问问小助手」进入时携带场景上下文
- **记账本** `pages/ledger`：支出/收入分类宫格取自 `ledgerCats` 域（用户可增改删，Swiper 每页 8 项横向翻页）；三等分大字栏（支出/收入/结余，结余负红正绿）+ 预算进度条（超支红）+ 今日/日均/可撑天数/环比；**flex 柱状趋势图（日/月/年 + 收支视角切换，月标题「2026 年支出」式）**；**分类占比卡固定高度**（Top3 横条 + 其余合并「其他」行 / 饼图点击联动，空数据灰色环「暂无记录」不塌陷）；**页内筛选条**（关键词 + 本周/本月/今年/自定义 + 分类多选，激活时范围=全量）；流水固定约 6 行内滚、按日分组，点击弹层编辑或删除
- **分类管理** `pages/ledger-cats`：支出/收入 tab；emoji + 名称编辑（「其他」锁定不可删不可改名，内置分类不可删），删除归并「其他」，账单批量联动
- **高级搜索** `pages/ledger-search`：关键词 + 起止日期 + 收支类型 + 分类多选 + 金额区间，结果按日分组只读
- **待办** `pages/todos`：三档优先级（🔴高/🟡中默认/🔵低，按级排序）；子任务展开勾选（全勾父自动完成）；**到期日期（dueDate）可设，到期自动滚入今日页「今日事项」**；"显示已完成"开关
- **周期提醒** `pages/periodic`：每 N 天到期判定（`daysBetween ≥ everyDays`），到期高亮置顶，「做完了」重置
- **重要日期** `pages/dates`：yearly 自动滚到下一个（生日）；倒计时排序；**可设提前 N 天提醒（remindDays，服务通知按此提前推）**；页面内呈现（不导出 .ics）
- **时政收集** `pages/notes`：五标签（时政/素材/心得/金句/其他）；「时政」自动进复习池；复习开关 chip；**喝水答错的错题本区**（逐题「已掌握/移除」管理）；搜索匹配正文或标签
- **番茄钟** `pages/pomodoro`（515 行）：双模式 🍅倒计时（15/25/45/60 或自定义 5~120，超限拦截）/ ⏱正计时（可暂停）；conic-gradient 圆环生长动画（🌰→🌱→🌿→🌸→🌼）；会话三持久化（module 变量+storage 三 key 防杀后台，挂载时补记录过期会话）；<1 分钟不记录
- **专注记录** `pages/pomo-logs`：今日合计+逐条（**日期+任务名两行布局防重叠**）；**周/月/年三档**（年档按月聚合 + 日期选择器跳任意日）；一周柱状+任务分布环图（Top5+其他）；一月 30 天迷你柱趋势 + **月任务分布环图**；三盒统计
- **心情记录页** `pages/mood-history`：周/月/年三档仪表盘——概览（均值+环比上一等长周期）、趋势列图（无记录天灰点断线）、5 档分布条形、低落回顾、时间线（限高 260px 内滑动）

## 设置页与子页

- **设置页** `pages/settings`：登录/身份区**精简为单行卡**（头像昵称可点进账号子页，不再长文案铺陈）；游客账号额外显示「升级为正式账号」按钮与**「演示数据 / 空白模式」开关**（个人主体小程序已移除身份预览切换）；正式账号仅显示「重置数据」
- **设置子页** `pages/settings-sub`：`?type=` 六合一路由：
  - `reminders` 作息与提醒（起床/睡觉/三餐/喝水间隔杯数）
  - `city` 天气城市（内置点选 + 搜索候选必点选 + **恢复自动定位**）
  - `intel` 智能推荐（口味偏好设置，存 settings；旧版 AI Key 页已删）
  - `notify` 服务通知（订阅消息额度「增加 1 条」授权累积 + 推送开关；每天 7:30 推到期周期待办/待复习闪卡/重要日期，生日等按 remindDays 提前；游客不推送）
  - `account` 账号与数据（身份/昵称/**升级为正式账号**/云端同步说明；替代旧版 backup+sync 两子页）
  - `about` 关于

## 游客演示模式（试玩账号）

- 游客**默认进入演示模式**：`buildGuestData()`（`src/mocks/fixtures.ts`）注入一整套演示数据——省考 30 天倒计时、连续 15 天打卡、3 张待复习闪卡、三件事进度、智能午餐推荐，另有心情/账本/番茄钟/奖券等氛围数据，日期全部相对当天动态生成
- 设置页「演示数据 / 空白模式」开关：
  - 切**空白模式**：清空业务记录（打卡/闪卡/记账等），仅保留设置项，从零开始
  - 切**演示数据**：重新调用 `buildGuestData()` 生成全新模板 → 回到「最初的样子」，无任何操作记录
- 切换状态由 `settings.guestDemo`（`true`=演示 / `false`=空白）持久化，重启后不误触发注入
- 游客数据只存本地沙盒 `kg-guest-data`，不落服务器（转正时才上传）；全程本地完成，不影响服务器

## 演示账号（开发期临时，上线前移除）

- 背景：开发者自己的微信 openid 已注册真实账号，无法再走游客演示模式；提供**账号密码登录的预置演示账号**查看运行效果
- 入口：设置 → 账号与数据 → 底部「演示账号（开发）」卡片（`src/components/DevAccountPanel.tsx`，仅开发期展示）
  - **登录演示账号**：账号密码 → `POST /auth/dev-login` → openid 签发 `dev-acct-*` 前缀（与微信身份完全隔离，role=user 数据真实落服务器）；账号无数据时自动灌入 `buildGuestData()` 演示数据
  - **重置演示数据**：一键恢复初始演示状态（仅演示账号下可见，防误覆盖真实数据）
  - **退出演示账号**：清本地登录态回到微信真实身份（演示数据保留在服务器）
- 账号徽章显示「演示账号」以辨识当前身份；日活统计不计该账号
- 去除清单（上线前）：`src/services/api/devLogin.ts` + `src/components/DevAccountPanel.tsx` + settings-sub 引用与徽章 + settings 徽章 + `server/main.py` `/auth/dev-login` 路由 + `server/config.py` `DEV_ACCOUNTS`（清空字典即可先禁用）

## 跨页机制（Taro 版）

| 机制 | 实现 | 备注 |
|------|------|------|
| 二级页导航 | `Taro.navigateTo` 原生页面栈 | 旧版 history.pushState hack 全废；侧滑/返回键天然支持 |
| TabBar | `app.config.ts` 原生 tabBar（text-only，图标待补 81×81 PNG） | |

| 横屏 | `pageOrientation: portrait` | 旧版横屏遮罩删 |
| 天气缓存 | storage 按坐标分 key，10 分钟 | 沿用旧语义 |
