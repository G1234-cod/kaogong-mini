## 一句话概括

**Taro 4 + React 小程序（15 页全部实现）**，用户首次打开二选一：试玩（游客，本地演示数据，不落库）或正式开始（微信静默登录，数据全量上云到自建 FastAPI 后端）；**主理人通过 B 端 Vue 3 管理后台**查看用户统计、发布任务（可选公开/隐藏、全员/指定）、发奖励券。天气/地理编码/一言/GLM 全部经后端代理（微信 request 合法域名须备案，外部服务均无备案）。

## 关键事实速查

- C 端：Taro 4 + React 18 + TypeScript strict；5 Tab + 10 个二级页 + 1 个设置子页；designWidth=390（旧 PWA px 值 1:1 直迁）
- 后端：FastAPI + SQLAlchemy + **SQLite**（连接串支持切 MySQL，切换零代码）；HMAC 无状态 token（180 天）
- 数据：注册用户全量上云（`user_data` 表按 AppData 域存 JSON，零 schema 漂移）；游客写本地沙盒命名空间，转正时打包上传
- 账号：**无白名单，注册制**（用户自己选择"试玩"或"正式开始"）；openid 即账号，无密码/无手机号（个人主体小程序也拿不到）
- 奖励：任务定义存服务端 `tasks` 表（B 端 CRUD），达成判定与状态在用户端（沿用旧版前端引擎），达成状态随 `rewards` 域上云；直接发券走 `grants` 表
- 项目根目录：`e:\project\kaogong-mini`（独立 git 仓库）；后端在其 `server/` 子目录
- 旧 PWA 不动，继续线上服务，直至小程序提审通过（见 [08](./08-部署与运维.md) 上线顺序）
