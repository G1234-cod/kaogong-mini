## 后端部署（server/）

部署文件已在 `server/deploy/`：`kaogong-api.service`（systemd）+ `kaogong-app.conf`（nginx 反代）。

```bash
# 首次
# 注意：不要用 scp -r server aly:/opt/kaogong-api/ —— 会把代码嵌套复制成
# /opt/kaogong-api/server/ 子目录，而 systemd 加载的是顶层 /opt/kaogong-api/main.py，
# 导致「本地改了、线上还是旧代码」（典型现象：新接口 404）。必须显式逐文件传到顶层。
scp server/config.py server/db.py server/main.py server/models.py server/security.py server/upstream.py server/requirements.txt aly:/opt/kaogong-api/
ssh aly
cd /opt/kaogong-api && pip install -r requirements.txt
cp .env.example .env   # 填 WX_APPID / WX_APPSECRET / ADMIN_TOKEN / GLM_KEY / DATABASE_URL
uvicorn main:app --host 127.0.0.1 --port 8000   # 手动验证
systemctl enable --now kaogong-api              # systemd 常驻（见 deploy/ 内 service 文件）

# 日常发版（改 server/ 后）——标准三步：先清库 → 再上传 → 最后重启
# 1. 清空测试数据（发版前必做，见下方「发版前清库」）
scp server/deploy/clean_db.py aly:/tmp/clean_db.py
ssh aly "/opt/kaogong-api/venv/bin/python /tmp/clean_db.py"
# 2. 上传代码（显式文件列表传到顶层，勿用 scp -r server，原因见上方注意）
scp server/config.py server/db.py server/main.py server/models.py server/security.py server/upstream.py server/requirements.txt aly:/opt/kaogong-api/
# 3. 重启（启动时自动 seed 10 项任务预设）
ssh aly "systemctl restart kaogong-api"
# 依赖变更时先 pip install -r requirements.txt
```

nginx：`kaogong-app.conf` 反代 `127.0.0.1:8000`，复用既有泛域名证书；B 端静态文件同域 `location /admin/`（alias 指向 `/var/www/kaogong-admin/`，SPA 回退 index.html）。

## 环境变量清单（server/.env）

| 变量 | 用途 |
|------|------|
| `WX_APPID` / `WX_APPSECRET` | code2Session（dev 未配则 code 派生伪 openid） |
| `ADMIN_TOKEN` | B 端唯一口令（X-Admin-Token） |
| `GLM_KEY` | 智谱 GLM（智能帮挑/地名纠错/安慰彩蛋），仅存后端 |
| `DATABASE_URL` | **生产 = SQLite `sqlite:////opt/kaogong-api/kaogong.db`**（2026-09 由 MySQL 迁入并校验；MySQL 已整体移除，表结构备份见 `/opt/kaogong-api/mysql-schema.sql`）；代码方言无关，切 MySQL 只改此行 |

## SQLite 备份

```bash
# /etc/cron.daily/kaogong-backup（每日执行）
sqlite3 /opt/kaogong-api/kaogong.db ".backup /var/backups/kaogong/data-$(date +%F).db"
# 保留最近 30 份，更早删除
```

`.db` 是单文件，冷备份即全量备份；B 端备份页展示最近备份时间。

2. **游客演示脚本**（面试官扫码即看）：省考倒计时 30 天 ✓ 15 天全勤热力图 ✓ 3 张待复习闪卡 ✓ 三件事进度 ✓ 智能午餐推荐 ✓ 隐藏任务提示条 ✓ 奖券袋含已入袋券 ✓——全部来自 `buildGuestData()` 动态日期
